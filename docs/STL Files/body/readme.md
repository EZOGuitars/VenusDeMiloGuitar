# Body STL Files

This directory contains **Venus De Milo body STL exports** and related body mesh references.

These files are useful for:

- 3D-print reference models
- CAM experimentation
- Fit / assembly visualization
- Derivative design work after import into compatible software

## Verify Before Manufacturing

Body geometry can change as the platform is refined. Before machining or printing from one of these meshes, compare critical features against the current source CAD in `docs/`, especially:

- Neck-pocket dimensions and location
- Bridge / scale relationship
- Pickup cavities
- Control cavity geometry
- Registration features
- Overall body thickness and variant

An STL is a manufacturing export, not necessarily the latest design authority.
