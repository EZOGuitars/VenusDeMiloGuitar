# Neck and Fretboard STL Files

This directory contains **Venus De Milo neck-system STL exports**, including neck, fretboard, nut, and related mesh geometry.

These files can be useful for:

- 3D-print reference models
- CAM experimentation
- Assembly / fit visualization
- Jig and fixture development
- Derivative design work

## Critical Geometry

Neck-system parts contain dimensions that directly affect playability and intonation. Before manufacturing from an STL, verify the current source CAD and your intended hardware/build specification, including:

- Scale length
- Fret positions
- Nut geometry
- Neck width and taper
- Neck-pocket / heel relationship
- Fretboard alignment
- Registration features
- Truss-rod requirements

Mesh exports can become stale as source CAD is revised. Treat the editable files in `docs/` as the preferred reference when confirming dimensions.
