# 3D Printing

This directory is reserved for **3D-print-specific resources for the Venus De Milo platform**.

The project uses additive manufacturing where it makes sense for builder tooling, fixtures, prototypes, and compatible accessories. As these resources are validated, this area can include items such as:

- Routing-template and guide components
- Registration aids
- Drill and layout guides
- Fixtures and assembly aids
- Pickup / electronics mounting components
- Printable accessory parts
- Recommended print-orientation and fabrication notes

## Before Printing

Verify critical dimensions against the current CAD and your actual hardware. Printed parts can vary with material, slicer settings, machine calibration, shrinkage, and seam placement.

Parts used with routers or other cutting tools should be inspected carefully before use. Confirm that guide surfaces, holes, registration features, and clearances are accurate on the finished print rather than assuming the nominal CAD dimension survived the printing process.

## Source vs. Export

Where possible, treat the editable CAD/reference geometry in `docs/` as the design source and printable exports as manufacturing derivatives. Check revisions before committing significant print time or material.

This directory will grow as shop-tested 3D-print workflows are documented.
