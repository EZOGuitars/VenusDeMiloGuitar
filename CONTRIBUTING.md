# Contributing to Venus de Milo

First off — thank you for taking interest in the Venus de Milo project.

This is an open-source CNC-first guitar platform developed under the EZO Guitars banner. The goal is to create modern, ergonomic, highly buildable instruments that are accessible to hobbyists, makers, luthiers, CNC users, and experimental builders alike.

Venus de Milo is an original instrument platform focused on modern design, ergonomics, and CNC-first manufacturing — not direct replication of existing guitar models.

It is an evolving instrument family with its own design language, construction philosophy, and identity.

---

# Project Philosophy

The Venus platform emphasizes:

- Modern ergonomics
- CNC-first workflows
- Builder accessibility
- Experimentation
- Boutique-inspired design language

The project welcomes:
- remixing
- experimentation
- derivative variants
- tooling improvements
- CAM workflows
- hardware adaptations
- electronics variants
- documentation improvements

---

# Before Contributing

Please review:
- existing Issues
- open Pull Requests
- current geometry standards
- naming conventions
- hardware assumptions

Avoid duplicating work that is already in progress.

If proposing a major geometry change:
please open an Issue first to discuss direction before investing significant time into CAD work.

# Design Language Guidelines

Venus de Milo designs should generally preserve the core identity of the platform.

Key visual characteristics include:
- flowing asymmetry
- ergonomic contouring
- compact modern proportions
- sculptural carve language
- aggressive but elegant posture

Derivative designs are encouraged, but direct cloning of other manufacturers is discouraged.

---

# CNC & CAD Standards

Preferred considerations:

- Parametric-friendly geometry where possible
- Clean manifold solids
- Consistent scaling
- Proper axis orientation
- Clearly named components
- Registration alignment support
- Manufacturing-aware tolerances

When submitting CAD:
- include source files whenever possible
- include exported STEP/STL formats when applicable
- document assumptions and dependencies

## Pull Request Expectations

Please include:
- screenshots or renders
- explanation of changes
- manufacturing considerations
- compatibility impacts
- tooling assumptions

If possible:
- provide prototype photos
- print tests
- machining validation
- assembly notes

---

# Hardware Philosophy

The platform currently favors:
- TOM-style bridges
- dual humbuckers
- bolt-on neck construction
- modern tuner layouts
- ergonomic heel transitions

Alternative hardware systems are welcome if properly documented.

# Licensing & Attribution

Please respect the project license and attribution requirements.
